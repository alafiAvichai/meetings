# מעקב פגישות — PWA אישי

אפליקציה קטנה לרישום פגישות טיפול: כפתור אחד במסך הראשי, וספירה חודשית.
כל הנתונים נשמרים במכשיר שלך בלבד (localStorage). אין שרת, אין חשבון, אין שליחה של שום דבר החוצה.

## הקבצים

```
index.html            המסך
app.css               עיצוב
app.js                הלוגיקה: רישום, ספירה, מחיקה, גיבוי
sw.js                 Service Worker — עבודה גם בלי אינטרנט
manifest.webmanifest  הגדרות ההתקנה למסך הבית
icons/                אייקונים
```

## מה האפליקציה עושה

- כפתור גדול "הייתי בפגישה" — לחיצה רושמת פגישה בזמן הנוכחי.
- אם כבר רשמת היום, תישאל אם להוסיף עוד אחת.
- אחרי כל רישום יש 8 שניות לבטל.
- מספר גדול = כמה פגישות היו בחודש שמוצג. חיצים למעלה מדפדפים בין חודשים.
- רשימת הפגישות של החודש, עם מחיקה לכל שורה.
- הוספה ידנית של פגישה שכבר היתה (תאריך + שעה).
- ייצוא ושחזור של קובץ גיבוי JSON.
- פתיחה עם `?log=1` בסוף הכתובת מדגישה את הכפתור ומציגה "הגעת לפגישה?" — בשביל האוטומציה למטה.

## העלאה לאוויר

צריך HTTPS, אחרת ה-Service Worker לא נרשם וההתקנה למסך הבית לא עובדת כמו שצריך.

**GitHub Pages** (חינם, הכי מתאים לשימוש אישי)

1. צור ריפו פרטי או ציבורי חדש, למשל `meetings`.
2. העלה אליו את כל הקבצים כמו שהם, בשורש הריפו.
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `root`.
4. אחרי דקה־שתיים תקבל כתובת כמו `https://<user>.github.io/meetings/`.

שים לב: ב-Pages גם ריפו פרטי מייצר אתר ציבורי. הכתובת לא מפורסמת בשום מקום, אבל אין בה סוד — הנתונים ממילא לא נמצאים באתר אלא רק בטלפון שלך.

**Netlify Drop** — חלופה מהירה: גורר את התיקייה ל-`app.netlify.com/drop` ומקבל כתובת.

**בדיקה מקומית** לפני העלאה:

```bash
cd meetings && python3 -m http.server 8000
```

ואז `http://localhost:8000` — localhost נחשב מקור מאובטח, אז גם ה-Service Worker יעבוד.

## התקנה באייפון

1. פתח את הכתובת ב-**Safari** (לא כרום).
2. כפתור השיתוף → "הוספה למסך הבית".
3. פתח את האפליקציה מהאייקון במסך הבית, לא מהדפדפן. רק ככה זה נפתח במסך מלא ומקבל אחסון יציב משלו.

## האוטומציה של ההגעה למקום

ב-iOS אפליקציית ווב לא יכולה לעקוב אחרי מיקום ברקע ולשלוח פוש. במקום זה אפליקציית **קיצורים** (Shortcuts) עושה את העבודה, והיא גם קוראת ישירות מלוח השנה — כולל יומן Google שמסונכרן לאייפון.

**קיצורים → אוטומציה → אוטומציה חדשה → הגעה (Arrive)**

1. בחר את המיקום של הפגישה, ו-"הפעל מיד" (בלי לשאול).
2. הוסף פעולות בסדר הזה:

| פעולה | הגדרה |
|---|---|
| Find Calendar Events | Start Date · is today. אפשר להוסיף תנאי Title contains "טיפול" |
| If | Count of Calendar Events · is greater than · 0 |
| Show Notification | "יש לך פגישה היום — אל תשכח לרשום" |
| End If | |

אם אתה רוצה שהאפליקציה גם תיפתח מוכנה לרישום, הוסף בתוך ה-If פעולת **Open URL** עם:

```
https://<user>.github.io/meetings/?log=1
```

זה יפתח את האפליקציה עם הודעה "הגעת לפגישה?" והכפתור מהבהב. עדיין צריך ללחוץ — בכוונה, כדי שלא ייווצרו רישומים מיותרים כשאתה סתם עובר באזור.

**רעיון עדיף לרישום עצמו:** בנה אוטומציה שנייה על **עזיבה (Leave)** של אותו מיקום, עם אותו תנאי לוח שנה, ובה `Open URL` לכתובת עם `?log=1`. הרגע שבו אתה יוצא מהפגישה הוא הזמן הכי טבעי ללחוץ על הכפתור, ואז הרישום גם משקף פגישה שבאמת קרתה.

## גיבוי

הנתונים חיים רק בטלפון. מחיקת האפליקציה ממסך הבית או ניקוי נתוני אתרים בספארי ימחקו אותם.
פעם בחודש שווה לפתוח "גיבוי ושחזור" → "ייצוא קובץ גיבוי", ולשמור את הקובץ ב-iCloud Drive או לשלוח לעצמך.
השחזור ממזג לפי חותמת זמן, כך שאותה פגישה לא תיכפל.

## עדכון גרסה

כשמעלים גרסה חדשה לאותה כתובת, צריך גם להעלות את מספר הגרסה בשורה הראשונה של `sw.js`:

```js
const CACHE = 'therapy-v2';
```

בפתיחה הבאה תופיע למעלה שורה "יש גרסה חדשה" עם כפתור רענון.
